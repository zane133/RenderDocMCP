# 风草顶点着色器分析（wind_grass VS）

> 来源：RenderDoc shader viewer 反编译（SPIRV-Cross 格式）
> 文件都在 `shaders/archive/gots_wind_grass/`
> 原始文件：`wind_grass_vs_dump.hlsl`（2457 行）
> 配套 PS：`wind_grass_ps_dump.hlsl`（3Dmigoto 格式）

---

## 1. 概述

这是**GPU 驱动的植被顶点着色器**，每个 draw 用 `SV_InstanceID` 索引到多条原始 Buffer 流（顶点流 / 3 条骨骼流 / 风参数流），在 VS 内完成：

- **双骨骼双链蒙皮**：同一局部顶点用两套骨骼矩阵 + 两套风参数分别模拟，链 A 输出渲染位置（`gl_Position`），链 B 输出次级世界位置（`TEXCOORD_5`）
- **LOD 分级**：`TEXCOORD_11`（uint）作为 LOD 等级 —— LOD 0 只做高度归一化弯曲，LOD ≥ 1 追加复杂风场位移
- **两级 Rodrigues 旋转弯曲**：随机 hash 扰动 + acos 多项式近似 + 风相位 sin 调制
- **风场双三次采样**：对三角形三边中点各做 4×4=16 次 `SampleLevel`（Catmull-Rom 核），含距离幂衰减与平滑截止
- **实例化索引解析**：4 组索引（法线骨骼 / 位置骨骼 / 顶点流 / 位置骨骼2）都加 `gl_InstanceIndex - gl_BaseInstanceARB` 偏移

## 5. 算法流程（两条平行链）

### 链 A（L92-1359）→ `gl_Position` + 切线/法线

```
实例参数解析 → 索引加载（_173/_175/_177/_266）
→ 顶点流/骨骼流读取（_18 法线 3×3、_19 位置 3×4）
→ NORMAL、TEXCOORD_2 解包 [0,1]→[-1,1]
→ 局部几何：POSITION 绕 TEXCOORD_7 旋转（_38_m0[7] 2D 旋转）
→ 蒙皮：3 参考点（TEXCOORD_7 / TEXCOORD_7+Δ8 / 旋转后 POSITION）× _19 矩阵
        → _527/_548/_569（世界空间三角顶点）
→ 法线蒙皮：2 组向量 × _18 3×3 → 归一化 → _606.._608、_613.._615
```

**LOD 分支 1** `_699 = TEXCOORD_11 > 0`（L367）：
- `if (LOD > 0)` 复杂弯曲：
  1. 随机 hash：`sin(dot(锚点和, (12.9898, 78.233))) * 43758.545` → `frac(_183 + ·)` → `_712`
  2. 三角边向量 → cross(边, 风方向 `_680/_681`) → 旋转轴 `_938.._940`
  3. `dot(法线, 风方向)` → **acos 多项式近似**（minimax 系数 0.74834597 / 1385.515…，阈值 |x|<0.93 双段）
  4. 风相位：`_183*1000 + _670*floor(_655/5+0.5) + (-0.01×边长)` → `sin()` → 振幅调制
  5. 弯曲角 = `(1-权重) × (茎长×角度上限 + 振幅×π/4×边长比)`
  6. **第一级 Rodrigues 旋转**（绕三角法线轴）→ 3×3 `_1592.._1613`
  7. **第二级 Rodrigues 旋转**（绕 cross(法线, 解包方向) 轴）→ 合成矩阵 `_2497.._2541`
  8. 应用：`_756 = _527 + R×(_569 - _527)`；切线/法线同步旋转 → `_761.._771`
- `else`（LOD 0）：直接用蒙皮结果 `_569..`、`_606..`、`_613..`

**基础弯曲（两 LOD 都走，L672）**：
- 高度归一化：`_778 = clamp((_759 - _223) / _38_m0[8].z, 0, 1)`，平方平滑
- 风相位：`_183*1000 + _670*floor(_634/5+0.5) + (-0.01×_778)`
- 摆动幅度：`lerp(-0.01, 0.03, (sin+1)/2)` × `_17[_139+4]`
- 弯曲角上限 π/4：`_817 = (茎长因子 + 幅度) × π/4`
- 绕风方向轴 Rodrigues 旋转 → `_881 = 锚点 + R×(_755 - 锚点)`（`_755` = LOD 分支结果）

**LOD 分支 2** `_934 = TEXCOORD_11 < 1`（L785）：
- `if (LOD 0)`：`_947/_949/_951 = _881.._883`（只用基础弯曲）
- `else`（LOD ≥ 1）**风场位移**（L797-1355）：
  1. 三角三顶点 `_527/_548/_569`，每对取中点 → 减风场中心 `_33_m0[18].yzw`
  2. 高度裁剪：`中点.z - _223 < 150` 才采样
  3. UV：`中点×0.0002 + 0.5` → `×256 - 0.5` → `frac` → **Catmull-Rom 权重**（`_1438 = -x³/3 + x²/2 + x/2` 等）
  4. **4×4=16 次 `SampleLevel`**（`_13[_17[_144]]` / `_8[_17[_884]]`，仅取 `.xy`）
  5. 风强度 `_903` 调制 → 位移向量
  6. **距离衰减**：`_1529 = z×(z<0?_927:_933)`；`exp2(_915×log2(dist²+100))` 幂衰减；`clamp(1 - _921×dist⁴)` 平滑截止
  7. 三条边各做一遍，位移平均 → `_2715/_2716`
  8. 若位移≈0（`<1e-6`）：用基础弯曲结果 `_881.._883`
  9. 否则：`sqrt(位移长)` 幅度 → 旋转轴 = cross(边方向, 位移方向)（归一化，NaN 防御）→ `acos(dot(边, 位移))` 角度（符号化）→ 混合系数 `_43_m0[21].z/.w` → Rodrigues 旋转边 → `_948 = _527 + R×(弯曲顶点 - _527)`
- 最终 `_947/_949/_951` → `gl_Position = WVP × P`

### 链 B（L1360-2406）→ `TEXCOORD_5`（世界坐标）

**与链 A 结构完全平行**，仅输入数据不同：

| 项 | 链 A | 链 B |
|------|------|------|
| 位置骨骼 | `_19`（索引 `_175`） | `_22`（索引 `_266`） |
| 局部 2D 旋转 | `_38_m0[7].xy` | `_38_m0[8].xy` |
| 参数区 2 | `_17[_139+56]` → `_665` | `_17[_139+64]` → `_1156` |
| 茎向量 | `_194/_195` | `_234/_235` |
| 方向 | `_205/_206` | `_246/_247` |
| 基础弯曲权重 | `_17[_139+16]` | `_17[_139+0]` |
| 输出 | `gl_Position`、切线/法线 | `TEXCOORD_5`（世界） |

蒙皮 3 参考点用 `_38_m0[8]` 旋转 + `_22` 矩阵 → `_1059/_1080/_1101`；之后 LOD 分支、两级弯曲、风场采样与链 A 镜像同构（风场计算复用同一 `_13[_17[_144]]` 纹理），最终 `_1653/_1655/_1657` → `TEXCOORD_5 = W × P`。

> 推断：链 A/B 对应植物两个部件的两套骨骼（如茎杆与叶片/穗），PS 中 `v5`（= `TEXCOORD_5`）作为次级位置参与距离/风相关混合。

## 7. 关键技巧清单（可复用）

1. **acos 双段多项式近似**：`|x|<0.93` 用 5 阶 minimax（`0.74834597·x⁴ - 1.098718·x² + 1.570796`），大值用 4 阶高次段 —— 避免 `acos` 指令
2. **Catmull-Rom 双三次**：16 次采样手工插值，权重 `-x³/3+x²/2+x/2`（`frac` 域），网格间距 `1/256`
3. **幂距离衰减**：`exp2(k·log2(d²+100))` + `clamp(1 - k·d⁴)` 双段（指数衰减 + 平滑截止）
4. **Rodrigues 旋转**：`R = I·cosθ + (1-cosθ)·aaᵀ + sinθ·[a]×`，轴 NaN/Inf 防御（`isnan/isinf` 检查后置零）
5. **GLSL hash**：`frac(sin(dot(p, (12.9898, 78.233))) × 43758.5453)`
6. **LOD 双分支**：`TEXCOORD_11 < 1`（简单路径）与 `> 0`（复杂路径）组合出 0/1 两档
7. **`precise` 标记**：SPIRV-Cross 对需要严格 IEEE 语义的指令（`mad`/`dot` 等）标 `precise`，还原时不可随意化简
